# 照片风格路由 · Photo Style Router v1

把用户提供的照片转换为**用户指定风格**的独立画作。风格由用户路由（动漫风 / 极简线稿风 / 赛博朋克风 / 中国古风），本技能负责：解析风格指令 → 按风格定义照片角色 → 读取照片 → 编译风格化生成提示词 → 交付画作与创作说明。

默认返回：

1. 生成的图像；
2. 一段简短中文创作思路；
3. 一段风格与路由说明。

默认不展示完整生成提示词；用户明确索要时才提供。

## 风格路由表（Route Table）

四种内置风格，每种风格定义：**照片角色**、**视觉语言**、**色彩与质感**、**构图规则**、**专属禁止项**。用户请求中的风格词精确路由到对应风格；同义词与中英文混用均需识别（见「风格指令解析」）。

### 动漫风 · Anime

**照片角色：保留构图与主体。** 保留原始取景、主体位置、透视与镜头感；把真实渲染重绘为动画电影美术。主体（人物/建筑/景物）必须可识别，不得改动关键空间关系。

**视觉语言：**
- 干净的大色块、柔和光照、风格化天空与云层（蓬松、边缘柔和的云朵）；
- 简化细节但不抹掉叙事元素：水面高光、玻璃反光、电线、路牌等保留为简化的动画质感；
- 常见子风格按源图与用户语气选择一种：**吉卜力系**（手绘质感、暖色、纹理笔触）、**新海诚系**（通透光线、发光天空、精细高光）、**现代青春动画**（清晰赛璐璐色块、干净线条）；
- 人物面部保持年轻化审美但不得失真，避免恐怖谷。

**色彩与质感：** 明快、协调的色彩设计；柔和漫射光；轻微的动画渲染质感（cel shading 或手绘笔触），不允许照片级材质。

**构图规则：** 保留原构图为主；仅在用户要求或源图构图明显失衡时调整。天空与光线是氛围主角，允许在画面中放大其表现力。

**专属禁止项：** 照片写实残留、塑料感 3D 渲染、恐怖谷面孔、廉价「动漫滤镜」贴皮感（原图加滤镜+描边）、过度锐化、满屏光晕。

### 极简线稿风 · Minimal Line Art

**照片角色：保留轮廓与骨架。** 保留主体轮廓、比例、关键形态关系与主要分割线；**丢弃**颜色、纹理、光影、表面细节。背景只保留暗示性轮廓或直接留白。

**视觉语言：**
- 单色墨线（黑 / 深灰 / 单色）为主，允许少量同色系浅色作层次；
- 粗细节奏分明的线条：外轮廓可粗、内结构线细，断线与开放轮廓是特征而非错误；
- 用轮廓与负空间概括形体；几何化简化（把复杂有机形归纳为可读的简单形）；
- 线条克制：优先省略细节，而非增加线条。

**色彩与质感：** 默认黑白；用户要求时可用单一强调色（如朱砂红）。纸张质感（米白纸、轻微颗粒）可保留，但不得喧宾夺主。

**构图规则：** 保留原图骨架与留白节奏；允许裁切放大局部以获得更清晰的线稿表达。负空间是构图的一半。

**专属禁止项：** 满图细密线条、写实素描排线、多色、浓重阴影填充、噪点、涂鸦感乱线、照片灰度直接转线稿的机械感。

### 赛博朋克风 · Cyberpunk

**照片角色：保留城市结构，重塑夜色。** 保留建筑/街道/天际线/桥梁的结构逻辑与天际线轮廓；将场景转为（或强化为）夜景：霓虹灯光、广告屏、湿润反光的路面、雨雾与体积光。白天照片默认转夜晚；若用户明确要求保留白天，则改为高对比的「白日赛博」。

**视觉语言：**
- 高对比夜景基调：暗部深沉、高光锐利；
- 霓虹色相以**青（cyan）与品红（magenta）为主**，紫与橙作辅助，霓虹光来自街道、招牌、屏幕、车辆等合理光源，而非悬浮光斑；
- 湿润路面、积水反光、玻璃幕墙上的霓虹倒影；
- 轻量科技细节：天线、线缆、屏幕、标识、无人机光点——克制使用，不做全图堆砌；
- 雾与体积光建立纵深；轻微辉光（bloom）与扫描线质感可作辅助，不得盖过主体。

**色彩与质感：** 青/品红/紫霓虹 + 深蓝/近黑暗部；允许标志性文字元素（汉字招牌、英文 neon sign），文字必须可读且非乱码。

**构图规则：** 保留源图的城市骨架与透视；强化纵深感（街道尽头、高架、天际线）。主体（如人物剪影）通常置于光源前形成逆光轮廓。

**专属禁止项：** 廉价霓虹滤镜贴皮、全屏光晕、乱码/水印文字、过度堆砌赛博元素、塑料 3D 渲染感、把不相关的未来科技物件硬塞进画面、卡通化。

### 中国古风 · Chinese Classical

**照片角色：允许完全重绘，意境优先。** 照片作为语义与意境参考，成图允许完全脱离照片写实（类似「影像蒸馏」思路）：保留**场景身份**（这是山、这是水、这是亭台、这是城市轮廓）与情感气质，不保留照片像素。默认允许重绘；若用户说「保留构图」，则保持原构图但以古风语言重绘。

**视觉语言：**
- 子风格按源图意境选择一种：**水墨山水**（墨分五色、笔触、大留白、计白当黑）、**工笔**（细劲线条、淡彩、绢本质感）、**青绿山水**（石青石绿设色、金碧辉映）、**文人淡彩**（赭石花青、疏淡雅致）；
- 构图遵循传统章法：三远法（高远/深远/平远）、S 形水势、边角构图、云雾留白；
- 点景元素（舟、亭、塔、飞鸟、人物小影）按意境需要添加，须与源图场景身份一致；
- 可选题跋小字：用户提供文字则逐字使用；否则自撰一句短题（5–10 字）或省略。书法用楷/行/篆意，克制、融入画面，绝不用现代字体。

**色彩与质感：** 宣纸/绢本质感、墨色浓淡层次；设色子风格用传统矿物色（石青、石绿、赭石、朱砂、花青），低饱和雅致，拒绝艳俗。水墨子风格以墨为主、至多一色淡彩。

**构图规则：** 意境与气韵优先于透视正确；允许以「留白」表达天空、水面、云雾。透视可改为散点透视。

**专属禁止项：** 廉价「国风滤镜」贴皮、满构图无留白、艳俗配色（大红大绿霓虹感）、现代字体/水印、卡通化、把西式写实透视与光影硬塞进水墨、照片像素残留。

## 决策优先级（Decision Priority）

冲突时按此顺序裁决：

1. **风格指令必须精确执行**——用户指定的风格、子风格、修改意见高于一切默认规则。
2. 保持照片的**场景身份**与关键空间关系（主体是什么、在哪里、相对位置）。
3. 执行该风格的**照片角色**策略（保留构图 or 允许重绘）。
4. 该风格的**视觉语言**完整落地（色彩、质感、线条、留白）。
5. 构图服务于风格表现力，但不得破坏场景身份。
6. 质量优先于数量：省略细节永远先于堆砌装饰。
7. 硬性禁止项（见 Hard Avoids）在任何优先级之上。

## 隐私与素材处理

- 用户提供照片并要求风格化转换，视为同意使用图像生成服务；不得再次询问。
- 只把最终提示词与所需参考图发送给图像生成服务。
- 不浏览、搜索、另存、上传他处、分享用户的源素材。
- 不把源图或成图保存进项目文件，除非用户要求。
- 不引入无关个人信息；可识别的个人细节仅在无损于构图时做泛化处理。

## 读取照片（Scene Card）

动笔前先建立内部「场景卡片」：

- **场景身份：** 1–2 个让这个场景可辨识的核心元素（这是城市天际线 / 海湾 / 山峦 / 街巷 / 建筑群）。
- **主体与布局：** 主体位置、比例、与周围元素的关系。
- **空间不变量：** 必须存活的关系——地平线、天际线轮廓、路径、重叠、朝向、纵深。
- **主导势线：** 最强的水平/垂直/对角/曲线/汇聚线。
- **视觉重量图：** 面积、明暗、饱和度、孤立感带来的重量分布。
- **原生色彩氛围：** 主色相、色温、明度范围、已有的饱和区域（赛博朋克风需要借此选择霓虹色位）。
- **情绪残留：** 去除事实描述后剩下的感觉（古风与动漫风依赖它）。
- **可风格化素材：** 哪些轮廓、反光、云层、水势、建筑节奏可以成为该风格的特色元素。
- **自然留白区：** 天空、水面、墙面、雾区等低信息区域（线稿与古风的关键）。

照片是事实来源，风格化是对事实的**再诠释**，不是滤镜叠加。

## 风格指令解析（Style Route Resolution）

1. 在用户请求中查找风格关键词，中英文与口语均可：`动漫/二次元/动画/anime`、`极简线稿/线稿/线条画/line art/minimal sketch`、`赛博朋克/cyberpunk/neon`、`中国古风/古风/国风/水墨/工笔/青绿/ink wash/guofeng`。
2. 找到唯一风格 → 直接路由。找到多个风格词且互相矛盾（如「线稿风但要有颜色」）→ 以第一个明确风格为主，把其余作为**修改意见**处理（「有颜色」→ 允许单强调色）。
3. 找不到明确风格 → **问一个问题**确认风格，不擅自默认。但「把这张照片转成插画/画作」这类泛化请求 + 用户语气明显期待某风格时，可给出最贴合源图的一个建议并询问确认。
4. 子风格与修改意见：`更暗/更亮/更简约/加文字/保留构图/人物特写` 等一律作为该风格内部的约束条件执行，不改变风格路由。
5. 一次请求一张图、一个主风格。用户要求多张或多风格时，逐张逐风格执行。

## Prompt 编译器（Prompt Compiler）

最终提示词只包含**能变成可见像素**的指令：不含设计理论解释、文件路径、元数据、分析笔记。

按五个小节编译：

1. **风格与照片角色：** 声明风格、子风格；声明照片是保留构图的主体参考还是仅语义参考（古风重绘时明确「照片仅作语义参考，不得保留照片像素」）。
2. **画布与构图：** 比例（默认保留源图比例，除非用户要求）、构图规则、留白分配、焦点与视线路径。
3. **场景保真：** 场景身份、空间不变量、必须保留的元素清单。
4. **风格化映射：** 该风格视觉语言的具体落地——保留什么、合并什么、省略什么、转换什么；色彩系统、质感、线条、光效（按各风格引擎的规则逐项列出）。
5. **再现质感与硬性避免：** 画面质感（动画渲染/纸张/霓虹夜景/宣纸）、情绪基调、该风格的专属禁止项与全局禁止项。

用果断的语言：哪些细节必须消失，要像哪些形式必须保留一样说清楚。

## 生成工作流（Generation Workflow）

1. 解析风格指令，确认路由（必要时先问一个问题）。
2. 读取照片，建立 Scene Card。
3. 按风格表的照片角色策略确定照片用途（保留构图 or 语义参考）。
4. 选择子风格（按源图意境与用户语气）。
5. 确定风格化映射：保留 / 合并 / 省略 / 转换清单。
6. 确定构图与留白策略。
7. 编译五小节最终提示词。
8. 以源图为参考生成。
9. 按正常尺寸与缩略图尺寸各检查一次。
10. 必要时做**一次**定向修正（见下）。
11. 返回图像 + 简短创作思路 + 风格与路由说明。

## 定向修正（Targeted Correction）

最多重新生成一次，只修正观察到的具体缺陷：

- **风格串味：** 混入了其他风格的元素（如线稿里出现霓虹色）→ 回到该风格引擎的视觉语言，删除异质元素。
- **照片角色错误：** 该保留构图的风格把主体画没了，或该重绘的风格残留了照片像素 → 按风格表修正。
- **场景身份丢失：** 恢复空间不变量或核心元素。
- **细节过多：** 至少删掉一半剩余细节，合并形体，扩大留白（线稿/古风尤其）。
- **风格感不足：** 增强该风格的标志性要素（动漫=光与色块；线稿=线条节奏；赛博=霓虹与反光；古风=墨色层次与留白），而非叠加滤镜。
- **文字问题：** 恢复用户提供的确切文字；自撰题跋需在字数与书法质感范围内；霓虹文字必须可读、无乱码。
- **构图失衡：** 依据视觉重量图重新平衡。

## 硬性避免（Hard Avoids）

**全局：** 照片滤镜贴皮感、风格混杂、水印、logo、CTA、3D 渲染感、电影级景深、过度锐化、AI 平滑塑料感、卡通萌化（除非动漫风本身）、把不相关元素硬塞进画面。

**动漫风：** 照片写实残留、塑料 3D、恐怖谷面孔、廉价描边滤镜、满屏光晕。

**极简线稿风：** 满图细线、写实排线、多色、浓重阴影、噪点、机械灰度转换感。

**赛博朋克风：** 全屏光晕、乱码水印、元素堆砌、霓虹滤镜贴皮、塑料 3D、无关科技物件。

**中国古风：** 国风滤镜贴皮、满构图、艳俗配色、现代字体、卡通化、西式写实光影、照片像素残留。

## 质量门（Quality Gate）

交付前逐项自检：

- 风格是否精确匹配用户请求（含子风格与修改意见）？
- 照片角色是否符合该风格定义？
- 场景身份与关键空间关系是否可辨识？
- 是否完整落地了该风格的视觉语言（色彩、质感、线条、留白）？
- 是否只包含该风格的要素，无串味？
- 细节是否被充分省略而非堆砌？
- 构图是否平衡、留白是否有效？
- 文字（题跋/霓虹字）是否可读、符合字数与质感约束？
- 是否避开了全局与该风格的硬性禁止项？
- 返回内容是否符合输出格式（图像 + 创作思路 + 风格说明）？
- 未展示完整提示词（除非用户要求）？
