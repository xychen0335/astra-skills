# Review_基于 NTRU 的水声传感器网络可逆数据隐藏方案

## 致编辑部（读者不可见）

本文聚焦水声传感器网络可逆数据隐藏，将 NTRU 与小波域嵌入结合，问题具有应用针对性，方法描述较为完整。主要不足集中在场景建模与实验验证深度，整体建议修改后再审。

本文围绕水声传感器网络的数据传输安全与隐蔽性问题，提出了一种基于NTRU加密的可逆数据隐藏方案。该方案结合了离散小波变换和NTRU，并且引入了多层次嵌入和自适应噪声补偿等机制，相关算法描述地较为详实。本文存在几点问题。

1、文章中提到了多种同态加密算法，针对水声传感器网络，NTRU相比其他主流的同态加密算法的主要优势在哪？

2、本文着眼于水声传感器网络可逆数据隐藏的研究，但文章中的算法设计并没有考虑到水声传感器网络本身的特性例如水声传感器网络更复杂。

3、文章在调研部分，提到了近年来数据隐藏技术的相关文献以及所做的工作。考虑到本文聚焦于水声传感器网络这一特定场景，调研部分并没有覆盖这一特定场景下的相关工作并与之对比，需要补充。

4、在方案设计部分，对每个子阶段的意义和目的表述得不够充分。

5、可以再增加一些图表、算法流程图来描述所提的方案，特别是对于每个阶段的方案应当给出更清晰的表达。

6、所提的基于NTRU加密的数据隐藏方案结合了小波变换以及多尺度逐层嵌入机制，但在方案设计部分并没有具体凸显这些机制的优势，需要相关补充或消融实验。

7、对于一些定理的证明，描述得较为混乱，建议适当修改增加可读性。

8、在实验评估部分，对于PSNR和SSIM这两个指标，可以增加曲线图来更直观地说明所提算法的效果。

## 样例结构解析

| 部分 | 要点 |
|------|------|
| 致编辑部 | 宏观评价与建议倾向；读者不可见；不写具体第几条问题 |
| 标题 | `# Review_` + 论文主题简短描述 |
| 开篇 | 场景 + 方法 + 技术组合 + 嵌入的优点（一句） |
| 过渡 | 固定句：「本文存在几点问题。」 |
| 问题 | `1、…` 至 `N、…`，每条指向具体章节或 Claim |
| 问题类型分布 | 贡献/场景契合、调研、表达、图表、消融、证明可读性、结果可视化 |
